# Lab-Pocket

![CI](https://github.com/sandhiyaL12/Lab-Pocket/actions/workflows/ci.yml/badge.svg)

**Project Code:** B-CODE-06

## Problem
ECE students often face slow and crowded college Wi-Fi while learning MicroPython and working with ESP32 and Raspberry Pi Pico boards. Finding the correct MicroPython functions and examples can be difficult.

## Who It Is For
ECE students, beginners, and lab instructors who work with MicroPython and embedded systems.

## Signature Feature
A lightweight, mobile-friendly MicroPython helper designed for low-bandwidth networks.

## Hardest Problem (Interview Story)
Configuring and deploying a FastAPI backend with Google Gemini API integration while handling environment variables, API failures, and Docker deployment.
